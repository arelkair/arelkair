## Featured

### [Wii Party Recomp](https://github.com/arelkair/wiiparty-recomp)

Static recompilation of Wii Party for PC — the game's code is translated into C++ and runs as a native Windows program, with no emulator. It boots, reaches the menu and has been played through a full game of Board Game Island at a steady 50 fps.

`C++` `Python` `Direct3D 11` `SDL3` · In development · [Case study](https://arelkair.dev/work/wii-party-recomp)

### [Nivra](https://nivra.arelkair.dev)

A private organizer for the browser — calendar, timetable, tasks, grades, money and more. No account: everything stays on your own device, and it installs like an app.

`React` `TypeScript` `Tailwind CSS` `Vite` · Live · [Case study](https://arelkair.dev/work/nivra)
